# RAVEN — Reddit read-only adapter

This directory documents the actual local Python adapter for NEXA's RAVEN research assistant. It is an offline prototype, not an approved Reddit app. The intended use is limited to approved, read-only access to public discussions in r/BetaReadersForAI, with human review. It does not send messages, comments, votes, or moderation actions. No credentials or private data belong in this repository.

Source files will be added after review. The application currently has no official Reddit API permission. The operator is u/Historical-Wheel-749, and the bot identity is u/NEXA_RAVEN_Bot.
